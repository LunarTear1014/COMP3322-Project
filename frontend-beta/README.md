# ClubSpace frontend beta

Start the Express API and MySQL using the [project setup](../README.md). From this
directory, run `npm ci` and `npm run dev`, then open the URL Vite prints.

Run `npm test` for the API and rendered fixture tests, `npm run lint` to lint, and
`npm run build` to build. `npm run preview` serves the build with the same local
API proxy. See the [integration notes](INTEGRATION.md) for available workflows.
